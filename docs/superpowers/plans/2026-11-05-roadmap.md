# PodCleaner-editor: roadmap

*[Version française](2026-11-05-roadmap.fr.md)*

**Spec:** [`docs/spec.md`](../../spec.md)

The brief covers six subsystems. Each one becomes a milestone with its own detailed plan, written when the milestone starts. Each milestone delivers software that runs and can be tested on its own.

## Milestones

| # | Milestone | Delivers | Depends on | Plan |
| --- | --- | --- | --- | --- |
| M1 | Foundations and analysis | Repository, CLI, reading the 3 tracks, per-track VAD, detection of silences, overlaps and film clips, cut map, `.md` edit file. End-to-end `--dry-run`. | — | [`2026-11-05-m1-foundations-analysis.md`](2026-11-05-m1-foundations-analysis.md) |
| M2 | Transcription and markers | Transcription of active passages only (mlx-whisper on Apple Silicon, faster-whisper elsewhere), word timestamps, voice markers (rapidfuzz), isolated "uh" candidates / ones to flag. | M1 | to write |
| M3 | Applied edit | Identical cuts on all 3 tracks with fades (silences + isolated "uh"s), final tracks, stereo mix, MIDI markers and markers in the mix WAV, remapped timecodes. | M1, M2 | to write |
| M4 | Studio sound | Per-track chain (DeepFilterNet, nara_wpe, EQ, compression, de-esser through ffmpeg), mix normalised to -16 LUFS / -1 dBTP, before/after measurements, test bench against the raw / Auphonic pairs. | M1 | to write |
| M5 | Claude layer (API, optional) | Opinions on "uh"s, sorting overlaps, marker variants, choice of settings, cut suggestions guided by already-edited episodes, log of opinions and cost per episode. | M2 (M4 for settings) | to write |
| M6 | Skills and release | `skills/` (full edit, report review, difficult episode), `.claude/skills/` (Auphonic comparison, 10-minute quick test, Windows compatibility), README, licence, macOS + Windows CI, Logic Pro validation. | M3, M4, M5 | to write |

M4 only depends on M1: it can move forward in parallel with M2/M3, in its own session.

## Suggested order

1. **M1** first: it sets the shared types (`Interval`, `Event`, `CutMap`, `Settings`) that every milestone uses, and gives a `--dry-run` that can run on a real episode as soon as it is done.
2. **M2 then M3**: the path to cut tracks usable in Logic Pro.
3. **M4** in parallel once M1 is merged: it is the longest milestone to tune (Auphonic comparison).
4. **M5** once transcription is stable.
5. **M6** last, with the Logic Pro test of the marker format.

## Test data needed

- One full raw episode (2 tracks + film) to validate M1 with `--dry-run`.
- A 10-minute excerpt of the same three tracks for the "quick test" skill.
- The raw / Auphonic pairs for M4.
- A few edited episodes with their raw recordings for M5.

These files stay out of the repository (`samples/` folder in `.gitignore`).
