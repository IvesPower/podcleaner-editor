# podcleaner-editor: roadmap

[Français](2026-11-05-roadmap.fr.md) · **English**

**Spec:** [`docs/spec.md`](../../spec.md) (translation of [`docs/spec.fr.md`](../../spec.fr.md), the reference)

The brief covers six subsystems. Each one becomes a milestone with its own detailed plan, written when the milestone starts. Each milestone delivers software that runs and can be tested on its own. Every milestone handles both recording layouts: `separate` (one WAV per voice + film) and `mixed` (one stereo WAV holding both voices + film).

## Milestones

| --- | --- | --- | --- | --- |

End-to-end `--dry-run`. | — | [`2026-11-05-m1-foundations-analysis.md`](2026-11-05-m1-foundations-analysis.md) |

M4 only depends on M1: it can move forward in parallel with M2/M3, in its own session.

## Suggested order

1. **M1** first: it sets the shared types (`Interval`, `Event`, `CutMap`, `Settings`, `Episode` and its layout) that every milestone uses, the CLI look, and gives a `--dry-run` that can run on a real episode as soon as it is done.
2. **M2 then M3**: the path to cut tracks usable in Logic Pro.
3. **M4** in parallel once M1 is merged: it is the longest milestone to tune (Auphonic comparison).
4. **M5** once transcription is stable.
5. **M6** last, with the Logic Pro test of the marker format.

## Test data needed

- One full raw episode (2 tracks + film) to validate M1 with `--dry-run`, and if possible one in the mixed layout.
- A 10-minute excerpt of the same tracks for the "quick test" skill.
- The raw / Auphonic pairs for M4.
- A few edited episodes with their raw recordings for M5.

These files stay out of the repository (`samples/` folder in `.gitignore`).
